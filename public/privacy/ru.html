Политика конфиденциальности

Telegram Reminder уважает вашу конфиденциальность.

Это приложение собирает только минимальные данные, необходимые для корректной работы. Единственный собираемый параметр — это Telegram User ID, который используется исключительно для привязки напоминаний к соответствующему аккаунту Telegram.

Персональные данные не продаются, не передаются третьим лицам и не используются в рекламных или маркетинговых целях.

Все данные передаются безопасным способом и используются исключительно для обеспечения основных функций приложения.

Приложение не собирает конфиденциальные персональные данные, финансовую информацию, медицинские данные, точные данные о местоположении, контакты, сообщения, фотографии или мультимедийные файлы.

Удаление данных

Пользователи могут в любое время запросить удаление своих персональных данных:

  • Отправив команду Telegram-боту (например: /delete или /stop)
  • Или связавшись с нами по электронной почте: support@telegram-reminder.app

После получения запроса все связанные данные (Telegram User ID, напоминания и статус подписки, если имеется) безвозвратно удаляются из наших систем.
